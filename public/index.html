Sobre este MVP

DriveWise é um projeto acadêmico para apoiar decisões e controle financeiro de motoristas de aplicativo.

O cadastro não possui autenticação individual. Para uso real com múltiplos usuários, serão necessárias contas, autorização e proteção de dados.

Os módulos de mapa e corrida são demonstrativos. Os dados financeiros exigem Node.js, Express e MySQL em execução.
